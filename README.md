# Design Studio Management System

A C++ console-based application designed to simulate a design studio pricing system.

## Overview

Design Studio Management System allows users to calculate the estimated cost of different design projects based on selected services, project specifications, and additional requirements.

The application supports three main design categories:

- **Fashion Design**: Clothing types, styles, quantities, prints, logos, and 3D visualization.
- **Interior Design**: Property area, property types, interior styles, service packages, technical drawings, and specifications.
- **UX/UI Design**: Digital project types, interface screens, complexity levels, interactive prototypes, and mobile adaptation.

## Features

- Interactive console interface
- Three design categories
- Dynamic project cost calculation
- Additional service pricing
- Automatic discount calculation
- Input validation
- Estimated project completion time
- Multiple project calculations in one session

## Installation and Usage

1. Clone this repository.
2. Open the solution in Visual Studio.
3. Build the project.
4. Run the application.
5. Select a design category and enter the project details.

## Currency

All project prices are calculated in Azerbaijani Manat (AZN).
